# おそらの しわけや

落ちてくる空のかけらを、同じ絵のかごへ運ぶ、小さな子ども向けのブラウザゲームです。

**あそぶ：** https://yanzefeng87-jpg.github.io/osora-no-shiwakeya/

## あそびかた
落ちてくる絵を指でつかんで、同じ絵のかごへ運びます（1回 約75秒。まちがえても終わりません）。

## 保護者の方へ
- 広告・課金・ログイン・データの保存はありません。ページを読み込んだあとは、外部と通信しません。
- 音は右上のボタンで消せます。一時停止は、あそぶ画面の右上にある二本線のボタンを約2秒長押しします。
- スマホの縦画面・パソコンのブラウザで遊べます。
